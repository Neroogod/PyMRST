## Status policy

- `ported`: a snake-case filename counterpart exists.
- `ported-consolidated`: the MATLAB symbol is explicitly referenced inside a consolidated Python module.
- `validated-reference`: a test or validation script explicitly names the MATLAB symbol. This does not yet grade validation depth.
- `excluded-catalog`: MATLAB `Contents.m` catalog only.
- `excluded-platform`: MATLAB MEX build/runtime source; its numerical fallback must still be ported and validated.
- `excluded-external`: optional external repository/data integration, outside the self-contained numerical core.
- `excluded-deprecated`: MRST explicitly deprecated the implementation; its active replacement behavior is provided by the facility layer.
- `excluded-visualization`: MATLAB graphics-only helper.
- `pending-review`: no defensible automatic mapping; requires manual classification or implementation.
