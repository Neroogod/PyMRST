# Optional compositional ML assets

This directory contains the seven legacy `model_runtest_beta2.2_fold*.pt`
PyTorch checkpoints that previously sat in the compositional package root.

They are not used by the MRST-compatible compositional simulator, are not
imported at module initialization, and are not required for the compositional
test or validation suites. They are retained here only as optional legacy ML
assets pending a separate documented inference workflow.
