## Status policy

- `ported`: a Python file at the MRST-shaped path implements the symbol. MATLAB dimension tokens are matched ignoring separators, so an honest filename port is not misreported.
- `ported-shim`: a file with the right name that only re-exports or forwards. Detected by parsing the module: it defines nothing, or every function it defines is a one-line forward to a sibling import. **Not counted as implemented.**
- `ported-consolidated`: a reviewed Python module implements the MATLAB function as part of a shared or public consumer. Matched against code only - docstrings and comments are stripped first, so prose describing a symbol cannot pass as an implementation.
- `pending-review`: no counterpart or exclusion exists; the `notes` column names the plan phase that retires it.
- `validated-reference`: a non-ledger test or validation script names the symbol; validation depth remains subject to review.
