## Status policy

- `ported`: a Python filename counterpart exists. MATLAB dimension tokens (`plotFaces2D`, `VEM3D_div`) are matched ignoring separators, so an honest filename port is not misreported as consolidated.
- `ported-consolidated`: a reviewed Python module implements the MATLAB function as part of a shared or public consumer.
- `excluded-mex`: a MATLAB MEX helper with no Python analogue, because PyMRST's AD objects are built directly.
- `pending-review`: no defensible counterpart or exclusion exists; the `notes` column names the plan phase that retires it.
- `validated-reference`: a non-ledger test or validation script names the MATLAB symbol or Python spelling; validation depth remains subject to review.
